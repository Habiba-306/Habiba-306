## 🏆 Featured Projects

### 🔍 ExamGuard — AI-Based Student Behavior Monitoring System
*Real-time exam proctoring combining YOLOv11m object detection with MediaPipe head pose estimation.*

[![GitHub Repo](https://img.shields.io/badge/View_Repository-181717?style=flat&logo=github)](https://github.com/Habiba-306/ExamGuard)
[![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)]()
[![YOLOv11](https://img.shields.io/badge/YOLOv11-00BFFF?style=flat&logo=ultralytics&logoColor=white)]()
[![Flask](https://img.shields.io/badge/Flask-000000?style=flat&logo=flask&logoColor=white)]()

- **Sensor Fusion:** YOLO detects invigilator ghost boxes; MediaPipe tracks head poses; IoMin suppression prevents false alarms
- **Behavioral State Machine:** Sliding window accumulator (5s window, 3s threshold) catches sustained suspicious behavior
- **Performance:** 91.9% mAP50, 95.8% invigilator detection, 83.0% phone recall
- **Full Stack:** Flask web app, live dashboard, automated PDF evidence reports
